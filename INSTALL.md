# GitHub Profile README Installation

## 1. Create the special profile repository
On GitHub, create a public repository named exactly:

```text
Nour-Ghribi/Nour-Ghribi
```

GitHub treats this as a special profile repository, and its `README.md` appears on the public profile page.

## 2. Copy this project
Copy the full project contents into the profile repository:

```bash
README.md
assets/
.github/
build_assets.py
INSTALL.md
```

## 3. Regenerate SVG assets after text changes
All animated SVG assets are generated by `build_assets.py`:

```bash
python build_assets.py
```

This preserves the template's original palette, layout, terminal styling, cards, and animations while updating the displayed profile content.

## 4. Activate the contribution snake
- Repository settings -> Actions -> General -> Workflow permissions -> enable read and write permissions.
- Open the Actions tab.
- Run `Generate contribution snake` manually once.
- The workflow then regenerates `snake-plum.svg` every 12 hours on the `output` branch.

## Notes
- GitHub stats, streaks, activity graph, typing SVG, badges, skill icons, and the contribution snake use external public services.
- The CVE research card is intentionally not linked because the matching public repository is currently empty.
- No remote repository has been modified by this local customization.
